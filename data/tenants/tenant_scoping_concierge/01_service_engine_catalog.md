## 3. Detailed Engine Technical Specifications

### Tier 1: Landing Page Core Engine (`landing`)
- **Layman Summary:** A single, ultra-fast, high-converting webpage engineered to capture leads, showcase brand identity, and convert visitors into paying clients.
- **Frontend Architecture:** Next.js 16 App Router with responsive motion UI, localized CSS Modules, and dual-mode Azure & Noir theme styling.
- **Conversion & Security:** Google reCAPTCHA v3 score-based protection on all lead capture forms; automatic spam honeypot filtering.
- **Performance & SEO:** OpenGraph social preview tags, JSON-LD structured schema markup, sub-second Largest Contentful Paint (LCP < 1.2s).
- **Recommended Maintenance:** Basic Care Plan (₹5,000 / $70/mo).

### Tier 2: Multi-Page Web App Core Engine (`multipage`)
- **Layman Summary:** A complete multi-page business website (Home, About, Services, Case Studies, Contact) featuring smooth page transitions and unified corporate branding.
- **Navigation & Routing:** Dynamic server-side layout shells across 3 to 6 dedicated pages; client-side prefetching for instant page navigation.
- **Motion & Accessibility:** Lenis smooth scrolling integration, accessible keyboard navigation traps, WCAG AA color contrast parity.
- **Recommended Maintenance:** Basic or Standard Care Plan (₹10,000 / $140/mo).

### Tier 3: Full-Stack SaaS MVP Core Engine (`saas`)
- **Layman Summary:** A production software foundation connected to a high-performance cloud database for platforms where users register accounts, manage private data, and execute software workflows.
- **Database Architecture:** Managed Supabase PostgreSQL with encrypted connection pooling, automated daily snapshots, and Row-Level Security (RLS).
- **Server Caching:** Aggressive Next.js `unstable_cache` layer with tag-based on-demand invalidation via authenticated revalidation webhooks.
- **Production Wiring:** Production Vercel serverless deployment, edge geographic routing, and custom domain SSL mapping.
- **Recommended Maintenance:** Standard (₹10,000 / $140/mo) or Premium AI SLA (₹35,000 / $475/mo).
