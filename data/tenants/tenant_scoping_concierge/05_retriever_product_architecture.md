Product Name: Retriever AI (Cognitive RAG Platform)
Production Gateway: https://rag.prateeq.in
Admin Cockpit: https://admin.rag.prateeq.in
Primary Use Case: Enterprise Document Search, Grounded RAG, AI Copilots
Core Embeddings: Local Ollama `nomic-embed-text` (768 Dimensions, $0 Compute)
Search Fusion: Hybrid Dense (HNSW) + Sparse (BM25) + ColBERT MaxSim Reranking

---

## 1. Product Overview & Enterprise Value Proposition

Retriever AI is a standalone cognitive search and generative question-answering platform designed for enterprises that demand data privacy, low latency, and verifiable accuracy:

1. **Un-bloated Hexagonal Alternative:** Replaces the fragile, fragmented LangChain + Pinecone + LiteLLM stack with a single enterprise-grade engine.
2. **100% Data Sovereignty:** Proprietary enterprise documents are processed and embedded locally on private VPS infrastructure. Sensitive data never touches public third-party AI APIs.
3. **Zero-Dollar Local Embeddings:** By leveraging containerized Ollama models (`nomic-embed-text`), document ingestion incurs zero per-token API costs.
4. **Verifiable Citations & Zero Hallucinations:** Every answer generated by Retriever is grounded in retrieved document chunks, returning clickable presigned citations with verified page numbers.

## 3. Developer REST API Specifications & Curl Snippets

### A. Hybrid Search Query (`POST /v1/search/hybrid`)
Executes a fused hybrid search query merging dense vector cosine distance with sparse BM25 keyword matching:

```bash
curl -X POST https://rag.prateeq.in/v1/search/hybrid \
  -H "Authorization: Bearer ret_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What are the payment milestone terms in the client contract?",
    "limit": 5,
    "strategy": "rrf",
    "threshold": 0.65
  }'
```

**Response Format:**
```json
{
  "results": [
    {
      "chunkId": "8f3b2e1a-4c5d-6e7f-8a9b-0c1d2e3f4a5b",
      "documentId": "1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
      "filename": "client_contract_sow.pdf",
      "score": 0.892,
      "content": "50% Upfront Deposit required to initiate development. 50% Final Balance prior to handover.",
      "metadata": {
        "pageNumber": 2,
        "isTable": false,
        "sectionPath": "Commercial Governance > Payment Milestones"
      }
    }
  ],
  "totalMatches": 1,
  "executionTimeMs": 38.4
}
```

### B. Streaming RAG Chat Completions (`POST /v1/chat/completions`)
Streams conversational responses via Server-Sent Events (SSE) with grounded citations:

```bash
curl -N -X POST https://rag.prateeq.in/v1/chat/completions \
  -H "Authorization: Bearer ret_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "What is the warranty period for new projects?"}
    ],
    "stream": true,
    "includeCitations": true
  }'
```

### C. Document Vector Ingestion (`POST /v1/admin/tenants/{tenant_id}/documents/upload`)
Uploads a document for layout-aware chunking, vector embedding, and full-text indexing:

```bash
curl -X POST https://rag.prateeq.in/v1/admin/tenants/1f85286c-9d9a-4ebc-9c62-a99360a5ece4/documents/upload \
  -H "X-Admin-Master-Key: YOUR_ADMIN_MASTER_KEY" \
  -F "file=@./service_catalog.pdf"
```
